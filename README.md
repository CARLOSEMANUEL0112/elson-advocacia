# Elson Aguiar | Advocacia & Consultoria Jurídica

Site institucional do escritório Elson Aguiar, com foco em Direito Previdenciário.

## Tecnologias

- React + Vite
- HTML, CSS e JavaScript
- Deploy na Vercel

## Como rodar

```bash
npm install
npm run dev
```

O site abre em `http://localhost:5173`.

## Build

```bash
npm run build
```
